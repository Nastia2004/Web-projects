# Design Patterns in Python

Навчальний репозиторій з простими прикладами патернів проєктування на Python.  
Кожен файл демонструє окремий патерн через невеликий, зрозумілий сценарій без зайвої інфраструктури.

## Що є в репозиторії

```text
patterns/
├── builder.py
├── facade.py
└── observer.py
```

## Реалізовані патерни

### 1. Builder
Файл: `patterns/builder.py`

Показує поетапне створення об'єкта `House` через:

- абстрактний інтерфейс `HouseBuilder`
- конкретну реалізацію `ConcreteHouseBuilder`
- клас `Director`, який керує послідовністю побудови

У прикладі можна побачити:

- мінімальну конфігурацію будинку
- повну конфігурацію будинку
- ручну кастомну збірку

### 2. Facade
Файл: `patterns/facade.py`

Демонструє, як клас `FoodOrderFacade` приховує взаємодію між кількома підсистемами:

- `Kitchen`
- `PaymentSystem`
- `DeliveryService`

Це хороший приклад того, як фасад спрощує роботу з кількома залежностями через один зрозумілий інтерфейс.

### 3. Observer
Файл: `patterns/observer.py`

Реалізує модель сповіщення на основі `WeatherStation` і служб новин:

- `TVNews`
- `InternetNews`

Станція погоди змінює температуру та повідомляє всіх підписників, які реагують по-різному.  
Приклад добре ілюструє зв'язок типу "один до багатьох".

## Як запустити

Переконайтеся, що у вас встановлений Python 3.

```bash
python3 patterns/builder.py
python3 patterns/facade.py
python3 patterns/observer.py
```
